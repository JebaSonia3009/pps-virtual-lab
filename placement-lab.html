Placement Lab

Programming for Problem Solving · All five units · Aptitude-style questions with worked explanations, and coding problems with test cases

Question bank

One hundred questions of the kind written tests actually ask: predict the output, find the mistake, judge the cost. Answer, press Check, and the explanation appears at once — reading the explanation for a question you got right is worth as much as reading the one for a question you got wrong.

Every question carrying a program has been run to confirm its answer, so where a question says a program prints something, it does. Questions are drawn in a different order each time, so going round a unit twice is not the same twice.

Coding problems

      
Fifteen problems of the kind set in an online round, each with the test cases the judge would
      use. Read the problem, write it in the editor below, and run it against every case — a
      solution that passes the first case and fails the last is the normal experience, and the cases are
      chosen to catch exactly that.

      
The empty input, the single item and the value at the boundary are where most
      submissions fall over. They are in the table for every problem.

Write your own

      
Write your answer to a coding problem here and run it. Run gives the output;
      Step walks through your own code line by line with the memory picture, which is
      the quickest way to find out where an answer went wrong.

      
Change the values at the top of your program to match each test case in turn and
      check the output against the expected column.
